# Achievement Desk 0.8.1 Preview

The first public Windows preview of Achievement Desk: a dark desktop workspace
for managing Steam achievements through the locally signed-in Steam client.

## Downloads

- **Windows portable ZIP:** extract the entire folder, then open `AchievementDesk.exe`.
- **Windows setup:** install for the current user, with optional desktop shortcut.
- **Source ZIP:** source code, documentation, tests and build configuration.
- **SHA256SUMS.txt:** SHA-256 hashes for the three download files.

End users do not need Python. Keep the portable executable, worker and `_internal/`
folder together. Start Steam, sign in and stay online before real account operations.

## Included

- Embedded A–Z library with search, 100-game pages, small Steam icons and
  account-scoped favorites/recent games.
- Achievement switches, full-list search/filtering, batch selections and explicit
  before/after review before applying changes.
- Steam-reported achievement sets/completion, set filtering and eligible remaining
  unlocks prepared as drafts.
- Local compatibility evidence, activity history, reference snapshots and exports.
- Trophy-and-sparkle branding, dark compact/comfortable layouts and shortcuts.
- Update lookup configured for this repository; it opens release pages on request.

## Validation and scope

The release workflow runs synthetic/offscreen tests, checks the frozen app and
worker, and tests silent installation/uninstallation in a temporary folder on a
GitHub Windows runner. These checks do not change a live Steam account.

A separately authorized real relock was acknowledged by Steam and confirmed in a
fresh worker process for one achievement in I Have No Mouth, and I Must Scream.
All 12 other achievement states/dates were unchanged. That evidence applies to
one operation and does not establish universal compatibility.

## Known limits

This is a **prerelease**, not a stable 1.0. Protected/server-controlled achievements
may reject edits. Steam controls trophy awards and persistence; relocking does
not guarantee trophy removal. Private game details may prevent completion checks.
Snapshots cannot restore historical unlock dates, trophies or game saves.
Native-interface compatibility can change with Steam updates. Broad real-game
coverage, upgrade behavior and end-to-end trophy-award timing remain to be validated.

Optional artwork requests use public Steam resources. Completion checks send
account/App IDs directly to Steam Community without cookies or credentials.
Both request types can be disabled separately in Settings.
